# Repository License Contract

## Ownership

Delino-owned source and future distributions use Apache-2.0. Root `LICENSE` contains the complete terms and `NOTICE` identifies the copyright holder. New repository-owned manifests must declare Apache-2.0.

## Imported material

Imported agent skills retain their upstream licenses, attribution and notices. A repository-wide default does not relicense imported material. Keep original licenses and copyright notices for any future imported source, fonts and assets.

The typeopt compiler dependency retains its complete license and upstream notice under `crates/typeopt/licenses`; historical compiler notices remain for provenance.

## Distribution

Future distributions must include the complete applicable license terms and notices. Validate package contents in the owning project's distribution checks. Typeopt currently supports Cargo source builds only; this repository publishes no prebuilt release artifacts.
